ngx-virtual-scroller

Render a list of any length with a few dozen DOM nodes. A virtual scroller for zoneless Angular: vertical or horizontal, single or multi-column, fixed or variable sizes.

How it works

The scroller measures your items, renders just enough of them to fill the viewport, and pads the space before and after so the scrollbar behaves as if every item were there. As you scroll, it swaps in the next slice of items. The number of DOM elements stays small and constant however long the list grows, so an "infinite" list costs about the same as a short one.

Features

  • Built for zoneless Angular

    No zone.js. viewPortItems and viewPortInfo are signal-backed, so OnPush templates update on their own.

  • Lists, grids and tables

    Multi-column grids are detected from your CSS layout. Render rows into a table body. Grid · Table

  • Horizontal and RTL

    Scroll sideways, in either direction. Example

  • Items of any size

    Fixed sizes are measured once, gaps and collapsing margins included. Variable sizes are measured per item. Example

  • Any scroll container

    Scroll the list itself, an ancestor with other content, or the whole page. Parent · Window

  • Infinite loading

    (vsEnd) tells you when the end is in view, so you can fetch the next page. Example

  • Scroll to anything

    scrollToIndex, scrollInto and scrollToPosition, with an optional eased animation.

  • No extra dependencies

    Angular and tslib, nothing else.

Get started

Import the standalone component, and render scroll.viewPortItems instead of your full array. Give the scroller a height, or point [parentScroll] at the element that scrolls. 

{{ quickStart }}

Set defaults for every scroller with provideVirtualScrollerOptions:

{{ options }}

To change the list, assign a new items array. Changes made to the same array in place aren't detected.

Coming from ngx-virtual-scroller?

This is the maintained fork of @iharbeck/ngx-virtual-scroller, which continued Rinto Jose's original ngx-virtual-scroller. The API is the same; version 22 drops what zoneless Angular no longer needs:

  • Angular 22 or later, zoneless only. Each Angular major gets a matching major here.
  • VirtualScrollerComponent is standalone. VirtualScrollerModule still works, but is deprecated.
  • provideVirtualScrollerOptions() (or the VIRTUAL_SCROLLER_DEFAULT_OPTIONS token) replaces the 'virtual-scroller-default-options' string token.
  • Removed: executeRefreshOutsideAngularZone, checkResizeInterval (resizes are observed instead of polled), detection of in-place array changes, and the @tweenjs/tween.js dependency.

To switch without touching your imports, alias the old name in package.json:

{{ alias }}
